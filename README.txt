GRIMOIRE DE THERKOS — VERSION 16

Cette version ajoute des illustrations fantasy originales aux cartes de sorts : thaumaturgie, assistance, flamme sacrée, illusion mineure, stabilisation, bénédiction, détection de la magie, sanctuaire, mot de guérison, soins, étincelle divine et renvoi des morts-vivants.

Installation GitHub Pages : décompresser l’archive, téléverser/remplacer tous les fichiers et le dossier spell-art à la racine du dépôt, puis valider (Commit changes). Ouvrir le site et actualiser avec Ctrl+F5.

Les images sont locales à l’application. Les données de jeu restent enregistrées dans le navigateur, comme dans la version précédente.
