GRIMOIRE DE THERKOS — VERSION PRO

CONTENU
- index.html : application web responsive en français.
- manifest.webmanifest + sw.js : éléments PWA pour installation sur l’écran d’accueil et cache hors ligne une fois hébergée en HTTPS.
- Sauvegarde locale automatique, export/import JSON, combat, fiche, sorts, inventaire, journal.

DONNÉES PRÉREMPLIES À PARTIR DES ÉLÉMENTS RETROUVÉS
- Therkos Dimitry, satyre, clerc de Kyrah, niveau 2.
- Sagesse 16, Constitution 14, maîtrise +2.
- 15 PV.
- DD de sorts 13, attaque magique +5.
- 3 emplacements de niveau 1, 2 utilisations de Canalisation divine.
- Langues : Commun, Sylvestre, Céleste, Draconique.
- Équipement notable : flûte.
- Flamme sacrée est indiquée comme sort évoqué auparavant, mais ses détails sont à vérifier sur la fiche.
- Historique : 400 XP mentionnés pour la session 2.

Les valeurs non confirmées (CA, initiative, vitesse, autres caractéristiques, domaine, historique,
compétences et liste exacte de sorts) restent vides ou à confirmer. Les informations affichées
ne remplacent pas la fiche officielle validée.

SAUVEGARDE ET SYNCHRONISATION
Cette version enregistre localement dans le navigateur. Elle ne synchronise PAS automatiquement
les appareils. Utilise Exporter/Importer pour transférer manuellement un fichier JSON.
Pour une vraie synchronisation, il faut héberger le site en HTTPS et connecter un backend sécurisé
avec authentification (par exemple Supabase ou Firebase). Les fichiers actuels ne contiennent aucun
secret et ne configurent pas encore ce backend.

UTILISATION
- Test local : décompresse le ZIP et ouvre index.html dans un navigateur moderne.
- Installation iPhone comme PWA : héberge le dossier sur un service HTTPS, ouvre l’URL dans Safari,
  puis Partager > Sur l’écran d’accueil. Le cache hors ligne dépend du navigateur et de l’hébergement.
- Exporte régulièrement la sauvegarde JSON.
